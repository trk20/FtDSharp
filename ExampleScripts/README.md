# ExampleScripts

Reference project containing example scripts from the mod README. Open this folder in VS Code for IntelliSense while browsing or adapting the examples.

Scripts live in `Scripts/`. Each file is a standalone example class — copy one into a Programmable Block to try it in-game.

## Requirements

Same as `ScriptProject/`:

- `../FtDSharp.API.dll`
- `../FtDSharp.dll` (for `Blocks.*` accessors)
- `../References/UnityEngine.CoreModule.dll`
